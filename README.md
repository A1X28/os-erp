# Ось

Учёт торговли и склада. Документ → проведение → движение склада → остатки и деньги.

Демо-компания: **Севертрейд** (стройматериалы, тенге, НДС 12%).

## Стек

| Слой | Что |
|---|---|
| Клиент | React 19, TanStack Router, Tailwind |
| Ядро | TanStack Start, серверные функции |
| База | PostgreSQL (`documents` → `stock_moves` → остаток) |

В превью без `DATABASE_URL` поднимается встроенный Postgres (PGLite). В проде — обычный Postgres.

## Вход

Книга общая на компанию. Без сессии сервер отвечает 401.

- Email + пароль (сотрудники)
- Google и X

Открыть `/login`. Регистрация пока открытая — не светить ссылку наружу, пока нет ролей и инвайтов.

## Локально

```bash
npm install
npm run dev
```

Открыть http://localhost:8080

Нужны Node 22 и npm. База в памяти процесса: после перезапуска снова сид «Севертрейд».

## Деплой

Ядро уже заточено под **Vercel + Postgres**. Достаточно:

1. Импортировать этот репозиторий в [Vercel](https://vercel.com/new)
2. В переменных проекта задать `DATABASE_URL` (Neon или любой Postgres 14+)
3. Deploy — миграции накатятся на сборке (`npm run build` → `db:migrate`)

Пустая база сама заполнится демо, если складов ещё нет.

**Не переписывать на Cloudflare D1 / SQLite** — ядро считает Postgres. Cloudflare имеет смысл только как DNS/CDN перед тем же приложением, не как база.

## Что уже есть

- Дашборд: выручка, маржа, склады, низкий остаток
- Документы: отгрузка, приёмка, перемещение, заказ, списание
- Проведение и отмена с проверкой остатка
- Номенклатура, контрагенты, остатки, отчёты

## Чего нет (пока)

- Ролей и инвайтов — любой, кто зарегистрировался, видит всю книгу
- FIFO / партий — себестоимость с карточки товара
- Отдельного регистра НДС
